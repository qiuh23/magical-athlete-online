# 首页入口对齐

基线：e275575a29dd595e841e5edc975d5077449272ec。范围仅为胡闹运动会首页和候场文案。

## 逐项验收

- [x] 保留品牌标题、角色主视觉、颜色、字体、背景和动效。
- [x] 首页动作从上到下为「创建房间」「加入房间」「单人练习」「人机对战」。保留运动会独有的人机模式，创建仍是列表唯一主按钮。
- [x] 加入房间在原按钮下方展开房间码与「加入」，不切换页面、不隐藏首页主视觉。参赛/观战、原身份恢复、本站限制、昵称验证和重复请求保护保留。
- [x] 单人练习只改首页入口；配置页的「自己练习」「开始自己练习」和规则正文保留。
- [x] 创建、练习、人机配置步骤及分模式草稿保留。
- [x] 公开房间位于动作列表下方；空状态为「暂无公开房间」，加载和连接错误分别显示。继续游戏入口保留并放在其后。
- [x] 首页/候场规则入口和弹窗标题为「玩法规则」，原有遮罩、右上关闭、Esc、焦点恢复保持有效。对局规则入口/标题不改。
- [x] 候场顶栏保留左侧可复制房间码、右侧「邀请朋友」「退出房间」的顺序。已有房主管理入口保留，未改对局顶栏。
- [x] 候场邀请按钮统一为「邀请朋友」，开局按钮为「开始游戏」。三人玩法选择、快速模式解释与开局逻辑不变。
- [x] 独立大厅、角色卡焦点/层级、游戏HUD、结算、游戏规则、网络协议和部署配置未修改；无跨仓库共享包。

## 验证与限制

新增 tests/home-alignment.test.ts，执行实际 Home/Modal 函数和确定性 hook 状态，覆盖入口顺序、原地展开/关闭/重开、输入保留、分模式配置、目录加入与观战、原身份恢复、昵称/异站拒绝、邀请入口、忙碌期间重复操作、规则关闭/焦点恢复，以及后加载样式覆盖。

完整源码/测试与 Worker 类型检查、双站构建、Worker 打包预演及内存单测均在本轮执行。七个需要 TCP 监听的测试文件（asset-cache、community-network、dual-backend-server、network、site-policy、security、network-backends）未在此受限本地工作区运行；已有正常 GitHub release Checks 继续运行其发布/网络契约，不改动或跳过工作流。保留既有大 chunk 构建提示。

按用户要求不运行浏览器视觉验收或截图，源码与行为测试不等同于浏览器渲染验收。发布仅使用正常 PR 检查、精确 head 合并、main 检查和原双站自动发布；最终公网版本与连接证据随交付报告提供。
