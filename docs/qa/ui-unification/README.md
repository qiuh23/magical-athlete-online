## 参考与边界

本次从远端最新主分支建立独立工作区，原三个仓库的未提交界面草稿保持原样。

两款游戏已落地的 `--ui-*` 变量作为共同词汇：系统字体、4px 间距、44px 操作目标、14px 圆角、1.7 SVG 线宽、150ms 反馈与可见焦点。Astryx 仅参考基础变量与主题覆盖分离的思路，未安装新组件或样式运行时。

运动会保留原配色、人物、赛道、GLB 棋子、动作和镜头。新增主题层只处理界面。比赛继续全屏，工具、头像积分、技能提示和操作悬浮；座位号放在头像角标，让负分和双位数总分有完整宽度。首页四种玩法入口直接可见，展开配置保留角色包、赛程、地图和特殊赛事；详细规则进入菜单，删除重复说明。

海外昵称前置到入口上方，仍关联原 `entry-form`，保留表单校验和草稿。聊天只在原海外组件上统一操作样式。国内固定随机昵称和无聊天方案、前后端站点策略、邀请/凭据/房间隔离均未更改。普通浮窗支持空白和 Esc 关闭，焦点返回触发控件；镜头设置使用同样的关闭习惯。

国内、海外大厅共用品牌和入口习惯，完整保留三款游戏插画及主题。跨站或无效邀请先保持入口禁用，用户明确选择“返回游戏选择”后才恢复本站入口，不自动跳转其他站点。
