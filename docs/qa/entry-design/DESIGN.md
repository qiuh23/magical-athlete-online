# 一起玩：大厅与游戏首页

## 入口规范

延续现有大厅的小型桌游与好友同桌气质。插画承担主题表达，控件承担操作层级。页面按「返回大厅/品牌与服务器 → 游戏标题与插画 → 玩法/开桌/加入/练习 → 规则等辅助入口」组织；现有建房配置和玩法选择保持可见，不增加菜单层级。

- 正文使用本机中文无衬线字体；游戏保留自己的标题字形。正文14–16px、辅助信息12–14px、标题按屏宽25–40px。规则细节在原规则菜单中。
- 按钮/输入框至少44px高，主要动作48px；控件圆角10–12px，较大容器14–16px。间距按8/12/16/24/32px组织。焦点有独立可见轮廓，不能只用悬停反馈。
- 大厅：浅草绿纸面 `#f2f5ef`、墨绿正文 `#233e34`、次级文字 `#617365`、主操作 `#32694f`、纸白 `#fffef9`。克制边线与柔和落地阴影。
- 运动会保留角色、跑道和明亮黄色，入口用绿色组织；巫师牌保留深色卡桌和暖金主按钮；卡坦岛保留海蓝/青绿与地图。每页只有明确的主操作重点，背景、正文与装饰不争抢注意。
- 返回大厅使用有文字的入口；服务器状态同时有文字，不只依赖颜色。图标使用一致线宽SVG并提供可访问名称。切换服务器、邀请优先级、身份隔离及部署配置沿用现有实现。
- 插画完整显示640×360画布，卡片不通过裁切掩盖绘图问题。手机允许正常纵向滚动，横屏不强制旋转，不把重要选项藏起来。
