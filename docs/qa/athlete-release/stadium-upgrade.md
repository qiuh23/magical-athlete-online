This record describes the integrated local candidate. Publication and automatic deployment are verified separately against their exact remote commit. Images are offline previews, not browser or phone GPU acceptance.

All seven courses have eight visible stadium fixtures. High quality uses six local spotlights and one local shadow; explicit economy uses four local spotlights and no local shadow. Both retain the lamp lenses and all mechanism assemblies. Daylight turns the lights off; the existing gradual 180-second, same-tab cross-round lighting clock remains unchanged. No rules, route ordering, saved room state or cache policy are changed.

High quality is the default on phones and desktops; saved choices remain authoritative. Demand/idle render intervals no longer downgrade quality. A sustained foreground animation slowdown can offer one nonmodal suggestion. Only its explicit lower-quality button changes quality; ignore, close, decline and reload do not repeat an already shown suggestion. Short screens omit this optional hint and retain the regular setting. This measures callback spacing, not GPU execution time.

## Limits

- Real WebGL pixels, complete phone matches, touch/soft-keyboard behavior, all-character continuous contact and actual phone frame rates are not certified. Geometry budgets are not draw-call/FPS measurements. Existing large-bundle build warnings remain.
- Full hardware visibility does not grant unverified physical contact. Wild 23/24 and Boardwalk 19/23 retain fixed outboard display mounts with targeted cosmetic feedback and the real event path/state. The 12 historical R1 contact cases are not current contact claims; unsupported/crowded cases preserve normal game logic without forcing an unverified bind.
- Fixed special counts exclude dynamic chips, traps and trampolines; these remain driven by actual match state. Mild/Bridges/Twisty have no fixed special tiles, so none were invented for a preview.
- The reviewed Wild and Boardwalks images use actual runtime camera framing and actual source geometry, three real banana models, complete tile numbers, environment and eight fixtures. Blender lighting/material response is an offline approximation; HUD and interaction are absent. Wild intentionally allows a small peripheral stand crop rather than shrinking gameplay for decoration.
- Default PR CI runs the existing release/contracts/build/dry-run scope, not the optional full gameplay/browser suites. Local full-suite and browser-DOM results above are separate evidence.
