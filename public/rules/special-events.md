# Thrilling Thirds · 网页适配

来源是用户提供的 `bgg464837.pdf`，Thomas G. 的非官方扩展，共36项事件。原文在第三场选手揭晓后翻开角色牌，依对应条目添加本场规则。本项目可在建房时选择适用场次，默认第三场；先锁定全部选手，再揭示事件，刷新不会重抽。特殊赛事默认关闭。

## 怎么使用

1. 创建房间时，在「特殊赛事 · Thrilling Thirds」中勾选启用；已有房间由房主在选秀开始前调整，并点击「保存本房间设置」。
2. 默认只勾选第3场，也可以更改为其他一场或多场。每个勾选场次只抽取1项事件，不是同时启用36项。取消全部场次时，需要重新勾选至少一场，或者关闭特殊赛事。
3. 到达指定场次，所有人选好上场角色后，系统自动抽取并在赛场展开显示本场事件。无需自行抽牌或提前选某个事件。
4. 照常掷骰；需要选目标、猜骰或确认时，按屏幕提示操作，其余效果自动处理。事件只对本场生效，刷新不会重抽，没有勾选的场次照常进行。

例如抽到「教练」：本场主移动增加同格其他选手的数量，系统会自动计算。

## 与原文的区别

- **事件签与实体角色牌分开。** 使用36个对应基础角色的事件签，洗混后依次抽取，用完重洗。不会因为扩展角色没有对应条目而偷偷重抽，也不会占用选秀牌。原文没有独立事件签，这是为混合角色包和长赛程采用的网页规则。实际抽取的额外能力牌仍来自本局同一个实体牌堆。
- **双人及额外选手。** 保留每人原有出场数量；重发角色按选手席位分配。半人马事件每人抽一张额外能力，授予自己的所有参赛者。每人猜一次；受益选手取该玩家固定顺序中第一名仍在赛的选手。左邻取固定顺序中下一位其他玩家的在赛选手。
- **身份与换牌。** 重发、传牌、交换牌保留位置和控制者，角色身份及能力资源随牌移动，当前回合的进度留在席位。模仿猫、双胞胎事件采用更换能力的方式，保留选秀身份；不补发已经过去的触发时机。双胞胎在赛前选择，因此可以执行新能力的赛前效果。
- **地图与标记。** NPC只作公共事件标记，不是运动员，不参与角色人数、名次或技能目标。分支处沿距终点最近的路线前进；后退沿反向相邻节点。标记到达终点后退出。女巫、飞艇主动接触与选手停到标记均生效；大嘴仅在选手停到标记时淘汰。蹦床由当前首位选手选择三个不同的非起终点格，只在停格时触发，按刚才这次移动的步数再移动，然后绊倒。魔术师事件直接换为 Wild Wilds；毛毛虫把15格设为本场起点，后退不会越过它。
- **主移动。** 角色对骰子的变更先完成，事件使用最终保留的主骰。无骰替代主移动没有猜骰结算。火箭博士事件两骰求和代替原主移动方法，仍应用移动修正；天才猜错时自己的移动也应用主移动修正。跟随者和猜中者的额外移动使用已公布骰值。催眠师的3格作为替代主移动基础值。
- **结算顺序。** 同一次停格先处理赛道格子，再处理本场公共事件，之后按当前玩家、其他玩家顺时针及同玩家固定选手顺序处理角色技能。赛道或事件将选手带离原落点后，新落点另行完整结算，不重复执行旧落点的角色停格效果；已经真实发生的越过效果保留。公共事件本身不计作某名角色发动能力，它引发的实际角色能力照常计数。回合开始与结束的事件按各自指定时机处理。
- **秘密猜测。** 依次提交、统一揭示；投影不包含其他人的已提交数字。大师猜中奖励在本场结算前入账，计入“事件分”。西西弗斯的支付逐人确认、可以对重掷继续支付；不允许负分。先手/平局比较骰和Twist内部的即时比较不开放支付窗口。
- **改变结束条件。** 讨喜的输家持续比赛到最后两名确定，最后一名领取本场第一档奖励、倒数第二领取第二档；淘汰者不领奖。大长腿每位仍有在赛选手的玩家完成至少一次回合后走5格，到终点时按赛道进度决定未颁名次，并列掷骰比较。NPC不会领名次。第二名已确定后按通常规则结束，未执行的移动不再继续；已确定的事件积分会在保存结果前结清。
- **循环。** 继续使用完整规则状态比较；强制反应环完整走过一遍后停止重复分支，保留其他待结算效果。分岔、跟随和低语目标选择属于同一移动链，刷新或再次点相同选项不会清空检测记录。固定骰与粘液事件强制重掷相遇时，一次后接受固定值，不生成假随机数。

这些是本项目公开采用的适配，并非原作者对扩展角色与多地图组合的官方裁定。历史规则版本的存档继续使用原引擎。

## 事件清单

完整36项已接入；具体名称与效果会在赛场常驻入口显示。公共标记和蹦床会显示在棋盘上。全部事件的来源时机、原文缺口及逐条对照见仓库 `docs/thrilling-thirds-source.md`。
