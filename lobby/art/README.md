# Lobby artwork

All three covers use the same 640 × 360 canvas, a raised tabletop composition and soft material shadows. Cards preserve that full 16:9 canvas with `object-fit: contain` on desktop and mobile. All artwork is served locally; no remote images, fonts or runtime libraries are required.

## Athlete

`athlete.svg` is an original vector redraw of this project's mint stadium board and existing hare, leaptoad and rocket-scientist character designs, informed by `src/client/scene/DioramaStadium.tsx` and `scripts/generate-3d-assets.mjs`. It does not copy third-party character assets. The foreground die is an inline SVG layer in `lobby/index.html`, so CSS can move just the die on hover, focus or touch. Its ground shadow stays still, and reduced-motion disables the movement.

## Wizard

`wizard.svg` embeds three existing, project-authored card illustrations from [`qiuh23/wizard-friends`, `src/assets/cards/`](https://github.com/qiuh23/wizard-friends/tree/db33eeb42118c57e3ad0cf6f4c7c3a3edb801987/src/assets/cards). The original paths, colours and card layouts are retained; SVG IDs and their references are prefixed to prevent collisions. The cover's felt table, paper edges, card back and prediction chips are original lobby artwork. The chips illustrate predicted trick counts, not betting.

## Catan entry

`catan.svg` is original code-authored vector artwork generated by `node scripts/generate-lobby-catan.mjs`. The 19 pointy hexagons use axial coordinates (radius 44); tile edges, intersections, road segments and coastal docks derive from that same topology. A single projection `(320 + x, 168 + .68y − z)` places the board and upright wooden buildings. The accompanying geometry test checks all 72 edges, 54 intersections, road endpoints, building anchors and coastal ports, plus reproducible output.

Forest trees represent wood, stacked red bricks represent clay/brick, white sheep represent wool, golden ears represent wheat, and grey faceted mountains represent ore. Number tokens use actual numerals (6/8 in red); three illustrative 3:1 docks connect to real coastline edges. This is a small lobby illustration, not an exact playable starting layout. It never imports or changes the Catan game's 3D board. No external images or official CATAN artwork are included. The game remains attributed to [Jack15678/catan-friends](https://github.com/Jack15678/catan-friends); this illustration does not add a license to the upstream project.
